# Categorization experiment record

Run `.\.venv\Scripts\python.exe -m evals.categorization_experiment` from the repository root after installing `evals/requirements-categorization.txt`. The default fixture is synthetic and deterministic (seed 2718, 144 rows, four categories). The chronological split uses 96 train, 24 validation, 24 test examples. The merchant-held-out split uses 64 train, 16 validation, 8 test examples and no test merchant appears in training. The model is TF-IDF with unigrams/bigrams and class-balanced logistic regression. Score thresholds are chosen only on validation. Reported metrics include accuracy, macro-F1, per-class precision/recall/F1, confusion matrix, top-3 accuracy, expected calibration error, high-score precision/coverage, and inference time. Baselines are learned exact merchant aliases, actual seeded alias rules, and simulated Plaid-like hints.

Measured on 2026-10-28 with scikit-learn 1.9.1: both classifier test splits had accuracy and macro-F1 1.0. The alias baseline matched all 24 chronological cases and no held-out merchant cases. Seed rules had zero coverage because the fixture has fictional names. The simulated hint baseline had accuracy 0.667 and 0.5; it is not a Plaid measurement. Calibration error was 0.201 chronological and 0.507 held-out. The local embedding comparison was skipped because no local model was configured. No model was deployed. The fixture phrases are simple and repeated, so these results are a pipeline check rather than meaningful real-world performance.

Optional `--source local` queries only new independently recorded explicit user corrections in memory, with a minimum-data abstention. Optional `--save-artifact` keeps joblib and metadata under ignored `.local/models`; never publish private trained artifacts. Optional `--embedding-model-path <existing-local-directory>` runs sentence embeddings without an automatic download.
